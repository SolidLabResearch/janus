# Historical Benchmark Results

The numerical tables formerly on this page are retained historical snapshots.
They were produced by earlier harnesses and lack the complete command,
revision, machine, and raw-artifact provenance required for a current Janus
performance claim. They must not be used as a release guarantee or copied into
the repository README.

Use [BENCHMARKING.md](./BENCHMARKING.md) to run the current backend benchmark
targets and record the command, Git revision, Rust version, machine details,
and raw outputs with each result set. For paper-oriented runs, use
[PAPER_BENCHMARKING.md](./PAPER_BENCHMARKING.md).

The versioned `data/result-analysis/` directory contains derived figures and
CSV summaries used by the README. It improves reviewability, but raw per-run
rows, commands, revision identifiers, and machine metadata are still required
for a fully reproducible artifact package.
