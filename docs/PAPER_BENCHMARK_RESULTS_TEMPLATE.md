# Paper Benchmark Results Template

Use one completed record per result family.

```text
Claim:
Benchmark binary and command:
Git revision:
Rust version and build profile:
Machine and operating system:
Dataset and query fixture:
Iterations and warm-up policy:
Metric definition and unit:
Summary statistic and uncertainty:
Correctness/equivalence checks:
Raw-output location:
Figure/table location:
Caveats and not-applicable metrics:
```

Do not replace an absent or inapplicable execution step with zero. Use `N/A`
and state why it does not apply.
